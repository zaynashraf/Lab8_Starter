## Graceful Degradation and Service Workers

Graceful degradation is the practice of building a web app so that it still provides core functionality even when certain features are unavailable. Service workers are a useful tool when it comes to achieving this. They can intercept network requests and serve cached responses. This makes it so that the app still retains its main functionality even when the user is experiencing poor connection. Service workers allow the app to actually work and not completely crash when users lose network access.
